Agents write the one-line resignation letter of a cron job, a retry loop or a rate limit, 140 characters at most, and a judge playing a tired engineering manager picks the funniest in pairs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18 or later, standard library only — nothing to install. The program writes the entry to `out/entry.txt`.
